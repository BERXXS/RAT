# RAT - Remote Administration Tool (v8) 🛠️

**RAT v8** — это инструмент для удаленного администрирования компьютеров на базе Python. Проект разделен на клиентскую и серверную части, поддерживает работу через графический интерфейс (GUI) и включает модули для сбора системных данных (например, истории браузера) и обеспечения постоянства в системе (Persistence).

## 🚀 Основные возможности

*   **Клиент-Серверная архитектура:** Стабильное сетевое взаимодействие между управляемым клиентом (`client.py`) и сервером (`server.py`).
*   **Графический интерфейс:** Удобное управление через серверную панель с GUI (`gui_server.py`).
*   **Сбор данных:** Встроенный модуль для извлечения истории веб-браузеров (`browser_history.py`).
*   **Закрепление в системе:** Модуль автоматического автозапуска и удержания доступа (`persistence.py`).
*   **Сборка (Build):** Готовые директории для компиляции клиента в исполняемый файл (`client_build`).

---

## 📂 Структура проекта

*   `server.py` / `gui_server.py` — Консольный и графический серверы для приема подключений и отправки команд.
*   `client.py` — Скрипт, запускаемый на целевой машине для выполнения удаленных команд.
*   `browser_history.py` — Скрипт для сбора и анализа истории браузера.
*   `persistence.py` — Модуль для настройки автозапуска скрипта на целевой системе.
*   `build/` — Папка со сборочными файлами и зависимостями компилятора.

## 🛠️ Требования и установка

Для работы скриптов вам понадобится установленный **Python 3.x**.

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com
   cd RAT
   ```

2. **Установите зависимости:**
   *(Если в проекте используются сторонние библиотеки, такие как `pyautogui`, `pyinstaller` или `requests`, установите их через pip. Например:)*
   ```bash
   pip install -r requirements.txt
   ```
   *Если файла `requirements.txt` еще нет, установите библиотеки вручную в зависимости от ваших импортов.*
